## Что такое Firebase Studio?

**Firebase Studio** — облачная агентная IDE от Google. В апреле 2025 Google переименовал **Project IDX** в Firebase Studio и объединил его с Firebase, Gemini и инструментами для разработки AI-приложений.

Идея простая: полноценная среда разработки прямо в браузере, без установки VS Code, Node.js, Python и всего что к ним прилагается. Открыл — и кодишь.

> Firebase Studio = Project IDX (облачная IDE) + Firebase (BaaS) + Gemini (AI-агент) в одном месте.

## Ключевые возможности

- **Облачные воркспейсы** на базе nix — полноценный Linux контейнер с любым стеком
- **Gemini in Firebase** — AI-ассистент прямо в IDE: автодополнение, объяснение кода, рефакторинг
- **App Prototyping Agent** — описываешь приложение, агент генерирует стартовую структуру
- **Полный стек:** веб (Next.js, Angular, Vue, Astro...), мобильные (Flutter, React Native + Expo), backend
- **Предустановленные шаблоны** — стартуй с шаблона под популярные фреймворки
- **Firebase App Hosting** — деплой прямо из IDE (с подключённым Billing)
- **Эмуляторы Firebase** локально в облаке — Firestore, Auth, Functions без внешнего интернета

## Отличие от Replit и Bolt

| | Firebase Studio | Replit | Bolt.new |
|---|---|---|---|
| **Инфраструктура** | Google Cloud | Replit Cloud | WebContainers (browser) |
| **Стек** | Любой (nix) | 50+ языков | JS/TS фреймворки |
| **AI** | Gemini | Replit Agent | Claude |
| **Firebase интеграция** | Нативная | Через API | Через промпт |
| **Flutter** | ✅ | ❌ | ❌ |
| **Бесплатно** | ✅ (3 воркспейса) | Ограниченно | ✅ (1M токенов) |

Firebase Studio — выбор если ты уже в экосистеме Google (Firebase, GCP) или делаешь Flutter-приложение.

## Тарифы (2026)

Firebase Studio **бесплатен** для индивидуального использования. Разница только в количестве воркспейсов:

| | Без программы | Developer Program (Standard) | Developer Program (Premium) |
|---|---|---|---|
| **Воркспейсы** | 3 | 10 | 30 |
| **Gemini квота** | Стандартная | Стандартная | Увеличенная |
| **Цена** | Бесплатно | Бесплатно | Платная подписка |

**Flutter и React Native + Expo:** без Premium — максимум 2 воркспейса этих типов суммарно.

<Aside type="note">
Подключение **Firebase App Hosting** для деплоя требует привязки Cloud Billing аккаунта. Само Firebase Studio при этом остаётся бесплатным.
</Aside>

## Установка и старт

<Steps>
1. **Открой [studio.firebase.google.com](https://studio.firebase.google.com)** (или [idx.google.com](https://idx.google.com) — редиректит туда же)

2. **Войди через Google аккаунт**

3. **Создай воркспейс:**
   - Из шаблона (Next.js, Flutter, Angular, Vue, Astro, Python, Go...)
   - Из GitHub репозитория
   - Через App Prototyping Agent — описываешь словами

4. **Подожди 30-60 секунд** — поднимается контейнер с полным окружением

5. **Работаешь как в обычном VS Code** — те же расширения, тот же интерфейс
</Steps>

## App Prototyping Agent

Самая мощная фича для вайб-кодинга — агент генерирует структуру приложения из описания:

```
Опиши своё приложение:
"Приложение для трекинга расходов.
Категории трат, месячный бюджет, графики.
React, TypeScript, Firebase Firestore."
```

Агент:
1. Выбирает подходящий шаблон
2. Генерирует начальную структуру файлов
3. Создаёт базовые компоненты
4. Настраивает Firebase конфиг

Дальше итерируешь через обычный чат с Gemini прямо в редакторе.

## Gemini в редакторе

Gemini доступен везде в IDE:

```
// Нажми Ctrl+Enter на любом коде
// или открой чат справа

"Объясни этот код"
"Добавь обработку ошибок"
"Напиши тесты для этой функции"
"Отрефактори под React Server Components"
```

**Code Actions** — наводишь мышь на проблемный код, появляется лампочка с AI-предложениями.

## Работа с Flutter

Firebase Studio — одна из лучших сред для Flutter разработки в браузере. Без XCode, без Android Studio:

```bash
# В терминале воркспейса — уже установлен Flutter SDK
flutter create my_app
cd my_app
flutter run -d web  # Запуск в предпросмотре браузера
```

Превью Flutter-приложения открывается прямо в IDE. Не нужен эмулятор.

<Aside type="tip">
**Flutter лимит:** без Premium подписки Google Developer Program — максимум 2 Flutter воркспейса. Удаляй старые или апгрейдись.
</Aside>

## Деплой

### Firebase App Hosting (встроенный)

```bash
# В терминале Firebase Studio
firebase init hosting
firebase deploy
```

Требует подключённый Billing аккаунт, но само базовое использование попадает в бесплатный tier Firebase.

### Vercel / Netlify через GitHub

```bash
# Синк с GitHub в один клик из Settings воркспейса
# Дальше стандартный деплой
git push origin main
# → автодеплой через Vercel/Netlify webhook
```

## Ограничения

- **Воркспейс засыпает** при неактивности (~30 мин) — пробуждение занимает ~10 сек
- **Flutter лимит** без Premium — только 2 воркспейса Flutter/React Native
- **Интернет обязателен** — это облачная IDE, offline не работает
- **Latency** — при медленном соединении набор текста может лагать

## Firebase Studio vs Google AntiGravity

Если у тебя возник вопрос "зачем два инструмента от Google?" — вот ответ:

| | Firebase Studio | Google AntiGravity |
|---|---|---|
| **Что это** | Облачная IDE (Project IDX наследник) | Агентная IDE (VS Code форк) |
| **Установка** | В браузере, ничего не надо | Скачать и установить |
| **Стек** | Любой, с фокусом на Firebase | Любой |
| **Фокус** | Firebase-экосистема, Flutter | Multi-agent разработка |
| **Цена** | Бесплатно | От $20/мес (AI Pro) |
| **Модели** | Gemini | Gemini, Claude, GPT-OSS |

**Firebase Studio** — если нужна облачная среда с Firebase и не хочется ничего устанавливать. **AntiGravity** — если нужна локальная мощная IDE с агентами и готов платить.
