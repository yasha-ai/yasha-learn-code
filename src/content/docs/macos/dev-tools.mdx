macOS имеет мощный набор CLI-инструментов специально для разработчиков — управление Xcode, подписью кода, фоновыми службами и системными настройками.

## xcode-select — Command Line Tools

Перед любой разработкой на Mac нужно установить Command Line Tools — это компиляторы, git, make и многое другое:

```bash
# Проверить установку
xcode-select -p
# /Library/Developer/CommandLineTools

# Установить (если не установлено)
xcode-select --install

# Сбросить путь к инструментам
sudo xcode-select --reset

# Переключиться на полный Xcode (если установлен)
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
```

## xcrun — запуск инструментов Xcode

```bash
# Найти путь к инструменту
xcrun --find clang
xcrun --find swift

# Запустить инструмент
xcrun swift --version
xcrun clang --version

# Симулятор iOS
xcrun simctl list devices
xcrun simctl boot "iPhone 15 Pro"
xcrun simctl openurl booted https://example.com
```

## defaults — системные настройки через терминал

`defaults` читает и пишет настройки macOS (plist файлы). Позволяет менять поведение системы без GUI:

```bash
# Показать скрытые файлы в Finder
defaults write com.apple.finder AppleShowAllFiles -bool true
killall Finder

# Скрыть скрытые файлы обратно
defaults write com.apple.finder AppleShowAllFiles -bool false
killall Finder

# Ускорить анимации Dock
defaults write com.apple.dock autohide-time-modifier -float 0.15
killall Dock

# Показывать расширения файлов
defaults write NSGlobalDomain AppleShowAllExtensions -bool true

# Отключить автоисправление
defaults write NSGlobalDomain NSAutomaticSpellingCorrectionEnabled -bool false

# Читать настройку
defaults read com.apple.finder AppleShowAllFiles

# Удалить настройку (сброс на дефолт)
defaults delete com.apple.finder AppleShowAllFiles
```

## launchctl — управление службами (LaunchAgents/Daemons)

macOS использует `launchd` вместо `systemd`. Фоновые службы — это `.plist` файлы:

```bash
# Список запущенных служб
launchctl list

# Найти конкретную службу
launchctl list | grep nginx

# Загрузить службу
launchctl load ~/Library/LaunchAgents/com.example.myapp.plist

# Выгрузить службу
launchctl unload ~/Library/LaunchAgents/com.example.myapp.plist

# Запустить/остановить
launchctl start com.example.myapp
launchctl stop com.example.myapp

# Пример plist для автозапуска скрипта
cat > ~/Library/LaunchAgents/com.yasha.myscript.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.yasha.myscript</string>
  <key>ProgramArguments</key>
  <array>
    <string>/bin/bash</string>
    <string>/Users/you/scripts/myscript.sh</string>
  </array>
  <key>RunAtLoad</key>
  <true/>
</dict>
</plist>
EOF
```

## plutil — работа с plist файлами

```bash
# Проверить валидность plist
plutil ~/Library/LaunchAgents/com.example.plist

# Конвертировать binary plist в читаемый XML
plutil -convert xml1 file.plist

# Конвертировать в JSON
plutil -convert json file.plist -o file.json

# Читать значение
plutil -extract Label raw file.plist
```

## codesign — подпись кода

```bash
# Проверить подпись приложения
codesign -dv /Applications/Safari.app

# Проверить валидность
codesign --verify /Applications/Safari.app

# Подробная информация
codesign -dvvv /Applications/Xcode.app

# Проверить Gatekeeper статус
spctl --assess --verbose /Applications/MyApp.app
```

## Полезные комбинации для разработчика

```bash
# Очистить DNS кеш
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

# Показать порты в использовании
sudo lsof -i -P | grep LISTEN

# Убить процесс на порту 3000
lsof -ti:3000 | xargs kill

# Сбросить иконки Dock
defaults delete com.apple.dock; killall Dock

# Показать IP адрес
ipconfig getifaddr en0

# Копировать SSH ключ в буфер
cat ~/.ssh/id_ed25519.pub | pbcopy
```

macOS — лучшая Unix-система для разработчиков именно из-за сочетания знакомых Unix-инструментов с уникальными системными командами.
